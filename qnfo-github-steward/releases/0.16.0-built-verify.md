# qnfo-github-steward 0.16.0-built-verify (2026-11-05)

ROADMAP-BUILT-VERIFY-1: psBuiltVerify moves a built, deployed or implemented roadmap item to verified when its rm-<id> remediation contract (module roadmap-dod-v1) has a passing verdict no older than 240 minutes, writes the contract's proof text and the built evidence into the row, retires the contract and closes the GitHub mirror in the same tick. Before, no loop verified such items (24 mirrors open 4 to 8 days on 2026-11-04). Tick output gains roadmap_built_verified and roadmap_built_waiting.
