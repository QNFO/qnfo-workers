## Immutability

Per ADR-013, each published version of the QNFO-ULA is immutable. No modifications are permitted without express written authorization from the Licensor. Version 2.1 was authorized by the Licensor on 2026-10-06 ("update it accordingly ... but I still want it all based on the QNFO ULA") and is published as new files; the v2.0 files are unchanged.
