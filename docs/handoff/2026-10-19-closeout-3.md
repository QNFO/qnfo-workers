## 3. What the reviews changed (so the next builder does not repeat it)

- A probe that reads only rows its own migration inserts is true the moment the file applies; q08's control probe therefore reads the deploy ledger. The live ledger trigger `deployment_history_version_monotonic_ins` refuses a lower version unless the notes say ROLLBACK-OK, and qnfo-ops never writes that word, so no probe can see a canary revert through the ledger; say so in the header instead of claiming it.
- A deploy gate keyed on a version number goes stale when another release lands at the same number: qnfo-research-exec took six releases (0.28.2 to 0.29.0) in a few hours. Gate on a number at or above the release and on the release tag, and re-take the number on every merge.
- A harness that scores an empty reply as a loss must say whether the model chose silence or the harness's token cap ended the reply (finish `length`); model_ab_runs ids 1 and 4 were the second case.
- A test that compares a bound to the exported constant cannot catch a changed constant; pin the literal.
- A repair that is documented as testing a behaviour the system makes impossible is a false claim; read the live trigger text from sqlite_master.
- A fixture with an absolute date is a time bomb the day a window passes it. Shift the fixtures by `Date.now() - FIXTURE_NOW` (3242) or pin the instant to noon UTC; do not pin the clock when other assertions read it.
- `git apply --3way` of a whole worktree diff carries merge noise from the branch; apply only the package's paths.
- D1 `changes()` counts rows written by AFTER INSERT triggers; a script that asserts "exactly one row" must select the row instead.

- A fresh `agent_issues` insert gets a born-superseded circular closing contract; changing the spacing of the `code-probe:` line afterwards fires the update trigger that writes the code-read contract. Check `remediation_contracts` after every insert (all eight wave-4 rows needed it).
- A code task cut for an issue that a session already fixed lands as an inert duplicate (3330); close it with the reason and set the task `superseded`, or the loop re-proposes it.
- The code loop's verifier accepted a patch that adds only two unused constants (3330); a task whose issue a session has already fixed is superseded by hand.
- A time-bomb sweep needs libfaketime, not a `Date` shim: a shim moves the JS clock and leaves SQLite's real, and fails about 300 suites that are fine.
- Python `urllib` is refused (403) by the deploy-guard host; use `curl` for work-lock calls.
