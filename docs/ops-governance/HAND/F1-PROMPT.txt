TASK: Repoint all Fleet AI consumers to Cloudflare AI Gateway dynamic routes

CONTEXT
Our AI cost audit (Oct 2026) found Workers AI spend of about $215/month, driven
mainly by the qnfo-agents worker calling @cf/moonshotai/kimi-k2.7-code directly
in tight loops (64k+ requests/month, 16k-34k input tokens each). To fix this,
three dynamic routes were deployed and verified ACTIVE on the "default" AI
Gateway. Your job: migrate every consumer from hardcoded model IDs to these
routes.

ENVIRONMENT FACTS (do not re-discover, use as-is)
- Cloudflare account: quniverse (ID: edb167b78c9fb901ea5bca3ce58ccc4b)
- Gateway ID: default
- Gateway endpoint (OpenAI-compatible):
  https://gateway.ai.cloudflare.com/v1/edb167b78c9fb901ea5bca3ce58ccc4b/default/compat/chat/completions
- From inside a Worker, use the AI binding:
  env.AI.run("dynamic/<route>", { messages }, { gateway: { id: "default" } })

THE ROUTES (already live -- do NOT create or modify them)
1. dynamic/value
   Chain: glm-4.7-flash -> qwen3-30b-a3b -> llama-3.2-3b
   Cost: $0.06 input / $0.40 output per 1M tokens
   Use for: bulk tasks, summaries, classification, glue work
2. dynamic/standard
   Chain: deepseek-v4.1-flash-1017 -> gemma-4-26b -> gpt-oss-120b
   Cost: $0.30 input / $1.20 output per 1M tokens
   Use for: DEFAULT for all general workloads
3. dynamic/premium
   Chain: kimi-k2.6 -> glm-5.2 -> anthropic/claude-sonnet-5.5
   Cost: $0.95 input / $4.00 output per 1M tokens
   Use for: hard reasoning/coding ONLY

Routes accept the OpenAI chat completions request shape only. The response
headers cf-aig-model and cf-aig-provider tell you which model actually served
the request.
