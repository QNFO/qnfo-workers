# qnfo-email 2.19.0-codeagent (2026-11-26)

NOTICE-OPPORTUNITY-1: the drafter reads a first-contact mail in context (earlier mail with the sender, the owner's field), judges whether it is a real opportunity (classifier field `opportunity`, a real person with a real opportunity is no longer dropped as uncertain tier 1), and writes a warm, specific reply that steers toward one easy next step. One model call per draft; the editor runs only when the first draft broke a rule. Owner feedback on a notice is understood: "interested", "not interested", "warmer/shorter" and similar rewrite the draft (one call) for the companion tap; "never corresponded" blocks and suppresses; nothing is sent to the sender.
