# personal-api 4.37.7

**Single-page companion UI restoration**

## Changes

Removed tab-based navigation UI introduced in 4.10.0 (Oct 19, 2026) and restored single-page scrolling design:

- **Removed navigation bar** with Today/Talk/Do/More tabs
- **All sections now visible** in single vertical scroll: Today, Focus, Capture, Talk, Do, Learn, Journal, Data
- **Removed tab-switching JavaScript**: `go()` now scrolls to sections instead of hiding/showing them
- **Removed `toggleMore()` function** and nav expand/collapse logic
- **Removed nav CSS** and `.hide` class usage
- **Updated main padding** from 96px bottom (for nav bar) to 24px
- **Updated toast positioning** from bottom 64px (above nav) to bottom 24px
- **All view functions initialize on page load** instead of on-demand when tabs clicked

## Technical details

- Removed `<nav>` element completely
- Removed `.hide` class from all `<section class="v">` elements
- Sections remain in DOM structure but all visible simultaneously
- Hash navigation now scrolls smoothly to sections: `#focus`, `#mood`, `#week`
- All initialization functions called on load: `load()`, `loadFocus()`, `inbox()`, `drawChat()`, `loadDo()`, `loadLearn()`, `loadJournal()`, `loadData()`

## Fixes

- Resolves user complaint about "shitty tab-based approach"
- Returns to "sleek well-designed screen" single-page layout
- Improves accessibility by making all content immediately visible
- Eliminates navigation friction - everything on one page
