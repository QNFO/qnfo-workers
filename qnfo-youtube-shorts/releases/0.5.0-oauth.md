# qnfo-youtube-shorts 0.5.0-oauth (2026-11-04)

YT-VOICE-1 and YT-SCRIPT-1 (pillar reach; minor: a new voice and a new director).
- Voice: Shorts are voiced in the render container by Kokoro-82M on CPU (Apache-2.0, no per-character cost), one pass per beat so intonation carries across sentence ends,
  with the model's own token times driving the word-highlighted captions. A failed first attempt returns the row to the voice stage, which re-voices with Aura/melotts.
  Image adds CPU torch, kokoro, espeak-ng and bakes the model in at build.
- Director: writes the whole voice-over first as a story (hook, stakes, idea with one everyday comparison, turn with the caveat, payoff, closing question), then cuts it into 5-7
  beats whose pictures illustrate the words instead of repeating them. Data templates (bignum, compare, payoff, meter, dots) only for figures the article states. The closing
  line varies per paper. The script is stored in beats.json. Director temperature 0.7; checker allows a flagged everyday comparison.
