## The rule that would stop this

A new artifact must **name and supersede a specific predecessor**, or amend it in place. A file that
neither supersedes nor amends joins the pile, and the pile is now large enough that adding to it is
a net negative regardless of the content.

## Failure modes against this index

- I enumerated filenames, **not contents**. Groupings in §5 are inferred from titles, so a file may
  be misfiled here.
- **I did not read the ~195 files.** "Canonical set" is a recommendation from titles and from the
  subset I did read, not a verdict from review.
- The count is ~195 for the `audits/2026-09-13` prefix only. `ops-workspace/` also holds `audit/`
  (singular), `AUTONOMY-GAP-FINAL.md`, `JOBS-STATUS-PUBLIC-1-CLOSEOUT.md` and others, and the
  `audits/` listing beyond the 09-13 prefix was truncated, so the true total is higher.
- This file is itself an addition to a corpus whose problem is additions.
