# qnfo-fleet-dashboard 1.94.0 (2026-11-05)

RM-LEE-CMD-1 (pillar autonomy): Lee, the Cloudflare-account assistant of lee.qnfo.org, is in the fleet command line. Deterministic reads cf workers, cf worker, cf versions, cf logs, cf zones, cf dns, cf routes, cf traffic, cf pages, cf deployments, cf stats answer with no model; lee: <question> runs a read-only tool loop (Workers AI, five steps, 40 s) as a polled job (cmd_log kind lee). Owner session only, on this worker's own CF_TOKEN and AI binding (no new secret). The write tools of the original (rollback, DNS and route changes, Pages create) are not ported: the loop has no write tool and a write tool the model invents is refused with no request. ops_config cmd_lee = off switches it off without a deploy. GET /api/cmd/lee/health reports per area (workers, zones, pages) whether the worker's token can read the account (booleans and statuses only), the closing probe of production serving Lee.
