# qnfo-ipatent 3.21.0 (2026-11-05)

REGISTER-1 (RM-BS-DEFENSIVE-PUBLICATION-1, pillar research; blue-sky bet B15): a consented register of defensive publications. /register lists disclosures whose holders of a saved draft's private link chose to publish; /register/publish records an explicit, never pre-ticked consent (exact text, version, time) and publishes only the disclosure text under a name the person chooses or none; each record has its own page with og tags, a cite-as line and a SHA-256 fingerprint anyone can recompute, /api/register for machines, and a withdrawal path (code or private link) that removes the text. Table public_disclosures is created lazily in ipatent-db. No DOI minting yet.
